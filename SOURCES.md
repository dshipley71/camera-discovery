# SOURCES.md

This registry is intentionally empty by default. Add user-approved public source URLs here when you want directory-mode discovery.

Allowed sources are used only in `directory` and `both` discovery modes. Blocked sources are a global deny policy and are respected by `blind`, `directory`, `both`, and `direct` modes.
